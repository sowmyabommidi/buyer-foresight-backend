# BuyerForeSight Backend Assignment

## 🚀 Live API

https://buyer-foresight-backend.onrender.com/users

## 📌 Features

* GET all users
* GET user by ID
* POST create user
* PUT update user
* DELETE user
* Search users
* Sort users

## 🛠️ Tech Stack

* Node.js
* Express.js
* File System (JSON)
* CORS

## ▶️ Run Locally

```bash
npm install
npm start
```

Server runs at:

```
http://localhost:5000
```

## 📮 API Endpoints

### GET all users

```
GET /users
```

### Search users

```
GET /users?search=sowmya
```

### Get user by ID

```
GET /users/:id
```

### Create user

```
POST /users
```

### Update user

```
PUT /users/:id
```

### Delete user

```
DELETE /users/:id
```
